BFSI Risk, Compliance & Underwriting Intelligence Platform

A Django-based financial intelligence platform integrating loan underwriting, fraud/risk analysis, AML investigation and early-warning workflows with GenAI and Agentic AI capabilities.

Features
- Loan Underwriting Engine
- Fraud Screening & Risk Scorecard
- AML Pattern Investigator
- Early Warning System
- GenAI-powered SAR generation
- AML investigator briefs
- Executive credit memos
- Customer notification generation
- MySQL database integration
- Interactive analytics dashboards
- Kaggle financial datasets
- Django multi-app architecture
